# Taskboard Timer
A desktop app built using Tauri, Flask, and React (using Material UI). It keeps track of tasks, sprints, and projects. Tasks are tracked in a combination of a Scrum Chart along the top (To Do, In Progress, Review, Complete) and a MoSCoW chart along left (Must Have, Should Have, Could Have, Won't Have). This is combined with the Pomodoro method.

Each time you want to begin working on a task, you choose a task and start a timer, usually for 20 minutes. Once that time is up, it's automatically added to the task. You can then start another timer either on that task or on a different task.
